# RadiocaseFa Android

Online Radiopaedia case reader: body-system and modality filters, user-tap collection of visible case links, persistent seen-case IDs, WebView image viewer, and on-demand Persian Gemini translation.

Use the `feature/radiocase-fa-v0.1.1` branch. GitHub Actions builds a debug APK. The app does not run a crawler or download the site in bulk. Radiopaedia can restrict access; site integration is experimental and is not endorsed by Radiopaedia. Set a personal Gemini API key in the app for translation. This is a beta, not medically validated.
